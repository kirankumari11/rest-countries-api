A web application that uses the REST Countries API to display information about countries. Users can search, filter, and explore country details with an intuitive interface and light/dark theme toggle.


Features:-
* See all countries from the REST Countries API on the homepage
* Search for a country by name
* Filter countries by region
* View detailed information about a country
* Click through to border countries on the detail page
* Toggle between light and dark mode


Tech Stack used:- 
* HTML
* CSS
* JavaScript
* REST Countries API


API Reference:-
* This project uses [REST Countries API](https://api.restcountries.com/countries/v5)
* [Link - Search by country code](https://api.restcountries.com/countries/codes.alpha_2/{code})
* [Link - Search by name](https://api.restcountries.com/countries/v5/names.common?q={name})
* [Link - Search by region](https://api.restcountries.com/countries/v5/region/{region})
